# แผนการนำเสนอ 7 นาที (Pitch + Live Demo) & คู่มือตอบคำถาม Q&A

> **วันที่จัดทำ**: 2026-11-16  
> **โจทย์นำเสนอ**: ครอบคลุม 6 แกนหลัก (ตั้งร้าน KYC · ลงขาย ISBN/คุณภาพ/เปรียบเทียบ · จัดส่ง 2 แบบ · ซื้อ 2 แบบ · LINE OA แจ้งเตือน · เติมเครดิต Business Model) ภายใน **7 นาที** โดยไม่ยืดเยื้อจนหลุดเวลา  
> **กลยุทธ์หลัก**: เดินเส้นเรื่อง **Live Demo** แบบ **Fast-Forward + Happy Path (นัดรับ)** ตามลำดับ `ตั้งร้าน (KYC) → ลงขาย (ISBN + คุณภาพ + เทียบ) → สั่งซื้อนัดรับ → รับออเดอร์ (-1 เครดิต + LINE OA + แชทซ่อนเบอร์ + นัด/รหัส 6 หลัก) → แตะหน้าเติมเครดิตตัดจบ` แล้ว **ย้าย Flow ส่งพัสดุ COD + ขั้นย่อยที่เหลือทั้งหมดไปเป็น Q&A Playbook พร้อมสไลด์/ภาพสำรอง**

## 1. ตารางจัดสรรทั้ง 6 หัวข้อ (แสดงสด vs เล่าเร็ว vs เก็บไว้ตอบ Q&A)

| หัวข้อที่ต้องการสื่อสาร | แสดงตรงไหนใน 7 นาที | เหตุผล & วิธีเล่าไม่ให้กินเวลา |
|---|---|---|
| **1. ตั้งร้าน + KYC** | **Live Fast-Forward (15 วิ)** | เปิดหน้า `/seller/setup` ที่กรอก/เตรียมไว้แล้ว ให้กรรมการเห็น **3 ด่านหลัก** (กันหลุดเบอร์/LINE ในชื่อร้าน, ปักจุดนัดรับ, กรอกบัตร 13 หลัก Mod-11 + PDPA ที่แอดมินเห็นเท่านั้น) แล้วกดไปหน้าถัดไปทันที **ไม่พิมพ์กรอกใหม่สดทั้งหมด** |
| **2. คนขายโพสต์ขาย (ISBN + คุณภาพ + เทียบ)** | **Live Fast-Forward (45 วิ)** | เปิด `/seller/list` โชว์สแกน/กรอก ISBN ดึงข้อมูลอัตโนมัติ + หน้า `step-3` เช็กคุณภาพ 5 จุดคำนวณเกรด `75/60/45/30%` → **สลับมาเล่มที่ Pre-stage ไว้บน `/book/[id]`** เพื่อโชว์ผลจริง + **ISBN Smart Compare** เทียบราคา/เกรด/`% ตรงปก` กับร้านอื่น |
| **3. คนขายจัดส่ง 2 รูปแบบ (COD & นัดรับ)** | **นัดรับ = Live หลัก / COD = สไลด์ + Q&A** | ใน Pitch Deck พูดชัดว่ามี 2 รูปแบบ (`นัดรับ ฿0` และ `ส่งพัสดุ COD ฿50 + ฿10/เล่ม เพดาน ฿150`) — **ตอน Live กดเฉพาะ "นัดรับ"** เพื่อจบ Loop ได้เร็วใน 3 นาที ส่วนหน้าใส่เลขพัสดุ COD เก็บไว้ตอบ Q&A |
| **4. คนซื้อสั่งซื้อ (นัดรับ & COD)** | **นัดรับ = Live หลัก / COD = Q&A** | กดจริงบนเครื่องผู้ซื้อเฉพาะ **`นัดรับ`**: ใส่ตะกร้า (`/cart`) → ส่งคำขอซื้อ → รอรับ → ยืนยันนัด → รหัส 6 หลัก (ส่วนเพิ่มที่อยู่ `/addresses/edit` + COD + ถ่ายรูปรับพัสดุ `/orders/[id]/receive` ตอบใน Q&A) |
| **5. แจ้งเตือน LINE OA** | **Live แบบ Real-time + สรุปใน Q&A** | เกิดขึ้นจริงระหว่าง Live **2 จังหวะสำคัญ**: ตอนผู้ซื้อกดสั่ง (LINE OA เด้งเตือนผู้ขาย) และตอนผู้ขายกดรับ (LINE OA เด้งเตือนผู้ซื้อ) พร้อมเล่าจุดขาย **Smart 2-Min Push Protection** ส่วนตาราง Event ทั้งหมดมีไว้กางตอบใน Q&A |
| **6. เติมเครดิต (Business Model)** | **Live ตัดจบ 15 วิ + สไลด์ปิด** | ต่อเนื่องจากวินาทีที่ผู้ขายกด `รับออเดอร์` แล้วเครดิตลด **`-1`** → แตะเปิด `/seller/credits` โชว์แพ็กเกจ **`฿20 (3)` / `฿50 (10)` / `฿100 (25)`** + **PromptPay QR + SlipOK** เพื่อปิดจบ Pitch แบบทรงพลัง |

> **สรุปคำถาม "ต้องย้ายบาง Flow ไปเป็นตอบคำถามหรอ?"**  
> **ใช่ครับ — แต่ต้อง "เกริ่นให้ครบใน Pitch Deck 30 วินาที" แล้ว "ย้ายการกดเจาะลึกของ COD + Edge Cases + Event แจ้งเตือนที่เหลือไปไว้ใน Q&A"** เพื่อให้กรรมการรู้ว่าเรามีครบทั้ง 2 รูปแบบโดยไม่โดนตัดไมค์ตอนกำลังกดหน้ากรอกที่อยู่หรืออัปโหลดรูปพัสดุครับ

## 2. ไทม์ไลน์นำเสนอ 7 นาที (Pitch 3:15 นาที + Live Demo 3:45 นาที)

```
0:00 ───────────── 3:15 ───────────────────────────────── 7:00
│  Pitch Deck (3:15)  │        Live Demo 2 เครื่อง (3:45)        │
│  Problem → Biz Plan │ Setup → List/Compare → Order → Accept → Credits │
```

### ช่วงที่ 1: Pitch Deck (0:00 – 3:15 | 3 นาที 15 วินาที)
1. **0:00 – 0:45 | Problem & Pain Point:** ตลาดหนังสือมือสองในกลุ่ม Facebook/แชท มีปัญหาสภาพไม่ตรงปก โกงโอนเงิน/บัญชีม้า นัดรับแล้วเบี้ยว และผู้ซื้อ-ผู้ขายแอบหลุดไปดีลกันเองนอกระบบ
2. **0:45 – 1:45 | Solution "จบในกองดอง" (บน LINE LIFF):** ไม่ต้องโหลดแอปใหม่ ทำครบใน LINE — ทั้งเช็กคุณภาพ 5 จุด, ระบบเปรียบเทียบราคาตาม ISBN, นัดรับด้วยรหัส 6 หลัก หรือส่งพัสดุ COD (`฿50 + ฿10/เล่ม` เพดาน `฿150`)
3. **1:45 – 2:30 | Architecture & Anti-Fraud (เกริ่น 3 เสาหลัก):**
   - **Pre-Accept Privacy Lock + Contact Masking:** ไม่เปิดเบอร์/LINE ID และซ่อนพิกัด/แชทจนกว่าผู้ขายจะกดรับ
   - **Seller KYC:** ตรวจ Mod-11 บัตรประชาชน + ชื่อจริง (เห็นเฉพาะแอดมิน)
   - **Smart LINE OA Notification:** ยิง Flex Card เฉพาะจุดเปลี่ยนสถานะสำคัญ + ข้าม Push อัตโนมัติถ้าอีกฝ่ายเปิด LIFF อยู่ภายใน 2 นาทีล่าสุด
4. **2:30 – 3:15 | Business Model (ปูทางสู่ Demo):** ลงขาย **ฟรี 100%** ไม่มีค่าคอมมิชชันต่อเล่ม — หัก **1 เครดิต** เฉพาะตอนผู้ขายกดรับออเดอร์ (`฿4–7/ออเดอร์`) *"เดี๋ยวไปดูของจริงใน Live Demo กันเลยครับ"*

## 3. คู่มือตอบคำถาม Q&A (Flow ที่ย้ายมาเก็บไว้หลังเวที)

เตรียมสไลด์สำรอง (Appendix Slides) หรือเปิดหน้าจอจริงโชว์ทันทีเมื่อกรรมการถามเรื่องเหล่านี้:

### Q1: "การส่งแบบพัสดุ COD ทำงานยังไง ผู้ซื้อและผู้ขายต้องทำอะไรบ้าง?"
- **ฝั่งผู้ซื้อ:** เพิ่ม/เลือกที่อยู่จัดส่ง (`/addresses/edit`) → เลือก **`ส่งพัสดุ (COD)`** ใน `/cart` → ระบบคิดค่าส่ง **`฿50` เล่มแรก + `฿10` เล่มถัดไป (เพดานสูงสุด `฿150`/ออเดอร์ สำหรับสั่งหลายเล่มหรือยกชุด)** → รอเลขพัสดุ → เมื่อได้รับของ กดถ่ายรูปยืนยันรับของและให้คะแนน (`/orders/[id]/receive`)
- **ฝั่งผู้ขาย:** กดรับออเดอร์ (`-1 เครดิต`) → ระบบจึงปลดล็อกชื่อ-ที่อยู่ผู้รับ → แพ็คของแล้วกรอก **ขนส่ง + เลข Tracking + รูปถ่ายกล่องพัสดุ** (`/orders/[id]/tracking`) → ระบบส่ง LINE OA แจ้งเลขพัสดุให้ผู้ซื้อทันที และหากไม่กดยืนยันภายใน 7 วันระบบปิดออเดอร์ให้อัตโนมัติ

### Q2: "LINE OA แจ้งเตือนในขั้นตอนไหนบ้าง? ไม่เปลืองโควตา Push เหรอ?"
- **เหตุการณ์ที่ยิง LINE OA Push Flex Card (พร้อม Deep Link เข้าหน้า `/orders/[id]`):**
  1. ผู้ซื้อส่งคำขอซื้อใหม่ (`NEW ORDER REQUEST`) → แจ้งผู้ขาย
  2. ผู้ขายกดรับออเดอร์ (`ACCEPTED / SCHEDULED`) → แจ้งผู้ซื้อ
  3. ผู้ขายปฏิเสธ (`ORDER REJECTED`) → แจ้งผู้ซื้อ
  4. ฝ่ายใดฝ่ายหนึ่งยกเลิก (`ORDER CANCELLED`) → แจ้งอีกฝ่าย
  5. ผู้ขายกรอกเลขพัสดุ (`SHIPPED`) → แจ้งผู้ซื้อพร้อมชื่อขนส่งและเลข Tracking
  6. เกิดเหตุไม่มาตามนัดหรือข้อพิพาท (`MISSED MEETING` / `DISPUTED` / `DISPUTE RESOLVED`) → แจ้งคู่กรณี
- **กลไกประหยัดโควตา (อ้างอิง [lineNotifyService.ts](file:///D:/Project/GongDong-Hack-DII/backend/src/services/lineNotifyService.ts#L182-L208)):**
  - ข้าม LINE Push อัตโนมัติถ้าผู้รับกำลังเปิด LIFF ใช้งานอยู่ภายใน **2 นาทีล่าสุด** (ให้เห็นผ่าน In-App Notification `/notifications` แทน)
  - เหตุการณ์ย่อย/ความถี่สูง (เช่น ข้อความแชท, นัดเวลา, ปิดงาน 6 หลัก, รีวิว) ตั้ง `pushLine: false` เพื่อไม่สแปมแชท LINE

### Q3: "ถ้าผู้ซื้อ/ผู้ขายโกง หรือนัดรับแล้วเบี้ยว ระบบจัดการยังไง?"
- **ก่อนรับออเดอร์:** ห้ามส่งข้อมูลติดต่อ, บล็อกเลขโทร/LINE ID ในชื่อร้านและแชท (`findContactLeaks` / `maskSensitiveData`), จำกัดคำขอค้างไม่เกิน 3 ออเดอร์
- **ระหว่างส่งมอบ:** นัดรับต้องใช้ **รหัส 6 หลัก** จากหน้าจอผู้ซื้อ (ล็อก 5 ครั้ง/15 นาที กันเดาสุ่ม); ถ้าผู้ซื้อไม่มาตามนัด ผู้ขายกดรายงาน **No-Show** (`/orders/[id]/no-show`) เพื่อคืนเครดิต และผู้ซื้อโต้แย้งได้
- **ข้อพิพาท:** กด **แจ้งปัญหา** (`DISPUTED`) → แอดมินเปิด [admin/page.tsx](file:///D:/Project/GongDong-Hack-DII/frontend/src/app/admin/page.tsx) (`/admin`) เห็นแชท, สลิป, รูปกล่อง/รับของ และข้อมูล KYC ครบในที่เดียวเพื่อตัดสิน

### Q4: "การลงขาย 'ยกชุด (SET)' รองรับต่างจากเล่มเดียวยังไง?"
