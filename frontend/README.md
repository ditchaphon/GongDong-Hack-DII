# Frontend · กองดอง

**ผู้รับผิดชอบ:** Farm

หน้าจอทั้งหมดที่เปิดใน LINE (LIFF) ตาม Figma prototype · โครงสร้างโค้ดในโฟลเดอร์นี้ Farm ออกแบบเอง

## ต้องมีถึงศุกร์ 13 พ.ย.

| รหัส Figma | หน้า |
|---|---|
| B1 | หน้าแรก / ค้นหา (กรองโซนนัดรับ) |
| B2 | รายละเอียดหนังสือ (รูป, เกรด, ผลเช็ก 5 จุด, ผู้ขาย) |
| B3 | ตะกร้า 1 ร้าน + เลือกวิธีรับ + ส่งคำขอซื้อ |
| B5 | สถานะออเดอร์ (เห็นเบอร์ + จุดนัด หลังผู้ขายรับ) |
| S2–S3 | ลงขาย 4 ขั้น: ISBN → รูป 4 ด้าน → เช็ก 5 จุด → ราคา + วิธีส่ง |
| S4 | ร้านของฉัน: เครดิต, เบอร์โทร, ออเดอร์เข้า, รับ / ปฏิเสธ |

## ข้อตกลงกับ Backend
- API contract: `../docs/API.md` (เขียนร่วมกับ Biw)
- ทุก request ที่ต้องล็อกอิน แนบ LIFF ID token
- กติกาเกรด / ราคาแนะนำ / ค่าส่ง ดู README หลัก (FE แสดงผล, BE คำนวณจริง)
