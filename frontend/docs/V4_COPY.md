## 1. Order statuses

| Code | Thai label | One-line meaning |
|---|---|---|
| REQUESTED | รอผู้ขายตอบรับ | ส่งคำขอแล้ว · หนังสือยังไม่ถูกล็อก ผู้ซื้อคนอื่นขอได้ |
| ACCEPTED | ผู้ขายรับแล้ว | เปิดแชทในออเดอร์แล้ว · นัดเวลาและจุดรับหรือชำระเงิน |
| SCHEDULED | นัดรับแล้ว | ยืนยันเวลาและจุดนัดแล้ว · ตรวจหนังสือและจ่ายเงินหน้างาน |
| PAID | ชำระเงินแล้ว | ตรวจสลิปผ่านแล้ว · ผู้ขายต้องจัดส่งภายใน 48 ชม. |
| SHIPPED | จัดส่งแล้ว | ผู้ขายแจ้งเลขพัสดุแล้ว · รอผู้ซื้อกดรับของ |
| COMPLETED | สำเร็จ | ปิดออเดอร์แล้ว · แชทอ่านได้อย่างเดียว |
| REJECTED | ถูกปฏิเสธ | ผู้ขายปฏิเสธคำขอ · ไม่เสียเครดิต |
| EXPIRED | หมดเวลา | ไม่มีการตอบรับภายในเวลาที่กำหนด |
| CANCELLED | ยกเลิกแล้ว | คำขอหรือออเดอร์นี้ถูกยกเลิก |
| DISPUTED | อยู่ระหว่างตรวจสอบ | แอดมินกำลังตรวจสอบ · เวลาทั้งหมดหยุดชั่วคราว |

## 5. Payment

- QR title: `สแกนจ่ายด้วยแอปธนาคาร`
- Warning: `ตรวจชื่อผู้รับในแอปธนาคารให้ตรงกับร้านก่อนกดโอน · ห้ามโอนเข้าบัญชีที่ส่งมาทางแชท`
- Demo note: `คิวอาร์ตัวอย่างสำหรับเดโม · ไม่ใช่ข้อมูลพร้อมเพย์จริง`
- Slip result:
  - CHECKING `กำลังตรวจสลิป` / `ใช้เวลาประมาณ 10–30 วินาที · ไม่ต้องปิดหน้านี้`
  - PASSED `ตรวจสลิปผ่าน` / `ยอดเงิน ชื่อผู้รับ และเลขสลิปถูกต้อง · ผู้ขายได้รับแจ้งแล้ว`
  - FAILED `ตรวจสลิปไม่ผ่าน` / `ชื่อผู้รับ ยอดเงิน หรือเลขสลิปไม่ตรง · ตรวจแล้วแนบใหม่ได้เลย`
  - ADMIN_REVIEW `ส่งให้แอดมินตรวจ` / `ระบบตรวจอัตโนมัติไม่สำเร็จ · แอดมินจะตรวจและแจ้งผลใน LINE`
- Slip privacy: `สลิปถูกเก็บแบบส่วนตัว · ผู้ซื้อและผู้ขายเห็นได้เฉพาะในออเดอร์นี้`

## 7. Credits

- Balance line: `1 เครดิต = รับได้ 1 ออเดอร์ · ลงขายฟรีเสมอ`
- Insufficient: `เครดิตไม่พอ กรุณาเติมเครดิตก่อนรับออเดอร์`
- Ledger reasons: `เครดิตฟรีสำหรับผู้ใช้ใหม่` · `รับออเดอร์` · `คืนเครดิต (ผู้ซื้อไม่มาตามนัด)` · `เติมเครดิต`
- Top-up warning (first order gate): `โอนจากบัญชีธนาคารของคุณเอง · ชื่อผู้โอนจะใช้ยืนยันบัญชีรับเงิน`

## 8. Identity & account

**Seller identity rule:** buyers see the **shop name** only. Real/payee name is kept for
payout verification and admin, never shown to the other side. Optional shop setting
(default OFF): `แสดงชื่อจริงเจ้าของร้านให้ผู้ซื้อเห็น`.

- Shop name label: `ชื่อร้าน`
- Shop name hint: `ชื่อร้านจะแสดงให้ผู้ซื้อเห็น · ห้ามใส่เบอร์โทรหรือไลน์`

- Nickname label: `ชื่อที่แสดงในกองดอง`
- Nickname hint: `ใช้ชื่อเล่นได้ · ห้ามใส่เบอร์โทร ไลน์ หรือชื่อจริง`
- PDPA: `ยินยอมให้เก็บชื่อเล่น รูปโปรไฟล์ และประวัติการซื้อขาย เพื่อใช้งานกองดอง ตามนโยบาย PDPA · ถอนความยินยอมได้ภายหลัง`
- Privacy note: `ชื่อและรูปจาก LINE จะไม่ถูกแสดงให้ผู้ใช้อื่นเห็น`
