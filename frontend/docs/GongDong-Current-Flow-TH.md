# GongDong — Flow ปัจจุบัน (สิ่งที่แอปทำได้จริงตอนนี้)

อัปเดตล่าสุด: 13 พ.ย. 2569 · ที่มา: โครงสร้างเส้นทางหน้าในโค้ด `frontend/src/app`

**ทางเข้าของทุกหน้า:** `https://liff.line.me/<LIFF_ID>/<path>`
ตอนนี้ยังไม่ได้ใส่ LIFF ID จึงรันในโหมดจำลองในเครื่อง (`NEXT_PUBLIC_LIFF_MOCK=true`)

---

## 1. ทางเข้าแอป

| หน้า | เส้นทาง | หมายเหตุ |
|---|---|---|
| หน้าแรก / ฟีดหนังสือ | `/` | ช่องค้นหา, หมวดหมู่, ฟีดหนังสือ, แบนเนอร์แนะนำ “เรื่องนี้คุณอาจสนใจ”, กระดิ่ง และตะกร้า |
| แนะนำการใช้งาน (ครั้งแรก) | `/onboarding` | จุดเด่น 3 ข้อ → เริ่มซื้อหรือเริ่มขาย |
| ตั้งชื่อ/รูปโปรไฟล์ | `/setup` | ใช้ชื่อและรูปจาก LINE เป็นค่าเริ่มต้น |
| Deep link | หน้าใดๆ ใต้ `/` | เปิดตรงได้ ใช้กับ Rich Menu / Flex Message ได้ |

## 2. Flow ฝั่งผู้ซื้อ

```
/ (ฟีดหนังสือ)
 ├─ /search                 ค้นหา + ตัวกรอง (หมวด, เกรด, ราคา, วิธีรับ, ISBN/ชื่อ)
 │    └─ /book/[id]         รายละเอียดหนังสือ + รูป + เกรด + เช็คสภาพ + หมวดหมู่ + ร้าน
 │         └─ /seller/[sellerId]   หน้าร้านสาธารณะ
 ├─ /cart                   ตะกร้า + เลือกนัดรับ/ส่งพัสดุ
 │    └─ /cart/success      ส่งคำขอแล้ว (ยังไม่ล็อกหนังสือ)
 ├─ /orders                 แท็บ “ที่ซื้อ” / “ที่ขาย”
 │    └─ /orders/[id]       รายละเอียดออเดอร์ + แชท + ปุ่มงานถัดไป
 │         ├─ /orders/[id]/schedule   นัดรับ: เลือกวันเวลา/จุดนัด
 │         ├─ /orders/[id]/tracking   ส่งพัสดุ: ผู้ขายกรอกขนส่ง/เลขพัสดุ
 │         ├─ /orders/[id]/receive    ผู้ซื้อถ่ายรูปยืนยันรับของ
 │         ├─ /orders/[id]/review     ให้คะแนนร้าน + สภาพตรงเกรดไหม
 │         └─ /orders/[id]/no-show    แจ้งไม่มาตามนัด (ยังใช้งานได้ แต่ซ่อนจำนวนในโปรไฟล์)
 ├─ /notifications          แจ้งเตือนผู้ซื้อ + แท็บแจ้งเตือนผู้ขาย
 ├─ /addresses              ที่อยู่จัดส่ง
 │    └─ /addresses/edit    เพิ่ม/แก้ไขที่อยู่
 └─ /help                   คู่มือ, ความปลอดภัย, เกรด, เครดิต, FAQ
```

### สิ่งที่ถูกซ่อนจากผู้ซื้อชั่วคราว
- จำนวน “ไม่ไปตามนัด” ในโปรไฟล์ — ซ่อนเฉพาะจำนวน ส่วนหน้าแจ้งไม่มาตามนัดยังใช้งานได้

## 3. Flow ฝั่งผู้ขาย

```
/seller                        ร้านของฉัน
 │                             - กระดิ่งแจ้งเตือน + กล่องออเดอร์ที่ top bar
 │                             - เครดิตแสดงในปุ่ม “เติมเครดิต · เหลือ X”
 │                             - แท็บ: หนังสือที่ลงขาย / ระหว่างทำการ / ประวัติการขาย
 ├─ /seller/setup              ตั้ง/แก้ร้าน 3 ขั้น
 │    ├─ ข้อมูลร้านค้า         ชื่อร้าน, รายละเอียด, รูป (ใช้ชื่อ/รูป LINE)
 │    ├─ ตารางจัดส่ง           วัน/ช่วงเวลานัดรับ + เปิด-ปิดรับส่งพัสดุ
 │    │                        (ไม่มีตัวเลือก “ส่งทุกวัน/ส่งภายในกี่วัน” แล้ว)
 │    └─ KYC                   เลขบัตรประชาชน + ชื่อจริง + นามสกุล เท่านั้น
 ├─ /seller/list               ขั้น 1: เลือกเล่มเดียว/ยกชุด + สแกนบาร์โค้ด ISBN
 │    ├─ /seller/list/details  ขั้น 2: ชื่อหนังสือ ผู้แต่ง สำนักพิมพ์ ราคาปก
 │    │                        รายละเอียด + หมวดหมู่
 │    ├─ /seller/list/step-2   ขั้น 3: รูป 4 มุม (กล้องหรือแกลอรี่) + รูปตำหนิ
 │    ├─ /seller/list/step-3   ขั้น 4: เช็กสภาพ 5 จุด → เกรดอัตโนมัติ
 │    ├─ /seller/list/step-4   ขั้น 5: ราคา + วิธีรับ + ค่าส่ง
 │    └─ /seller/list/success  ลงขายสำเร็จ
 ├─ /seller/listings/[id]/edit แก้ไข/ซ่อนประกาศ
 ├─ /seller/credits            แพ็กเครดิต (Starter / Bookworm / Merchant)
 │    ├─ /seller/credits/pay   QR + สลิป (เฉพาะการเติมเครดิตแพลตฟอร์ม)
 │    ├─ /seller/credits/success
 │    └─ /seller/credits/verify
 └─ /seller/report             แจ้งปัญหา
      └─ /seller/report/sent
```

### กติกาหน้าร้าน
- ประกาศที่มีคำขอซื้อ (`REQUESTED`) จะถูก **ซ่อนชั่วคราว** จากแท็บ “หนังสือที่ลงขาย” และย้ายไปกลุ่ม “ซ่อนชั่วคราว · มีคนขอซื้อ”
- ประกาศที่มีคำขอหรือออเดอร์ที่ยังไม่ปิดจะ **ล็อกการแก้ไข** (ราคา/วิธีรับ/ซ่อน)
- แท็บ “ระหว่างทำการ” แสดงทั้งคำขอที่รอตอบรับและออเดอร์ที่กำลังดำเนินการ

## 4. Flow ออเดอร์ — เก็บเงินปลายทาง (COD)

ไม่มี QR หรือสลิปในออเดอร์แล้ว ใช้เงินสดตอนรับหนังสือ/รับพัสดุเท่านั้น

```
นัดรับ:
REQUESTED (รอรับการยืนยัน) → SCHEDULED (นัดรับแล้ว) → COMPLETED (รีวิว/ถ่ายรูป)

ส่งพัสดุ:
REQUESTED (รอรับการยืนยัน) → ACCEPTED (ยืนยันการส่ง) → PAID (เก็บเงินปลายทาง) → COMPLETED (รีวิว/ถ่ายรูป)

ออกจาก flow: REJECTED, EXPIRED, CANCELLED, DISPUTED
```

### การซ่อนข้อมูลก่อนผู้ขายยืนยัน
- ทั้งผู้ซื้อและผู้ขายจะ **ไม่เห็นสถานที่/เวลารับหรือที่อยู่จัดส่ง** ในสถานะ `REQUESTED`
- ข้อมูลจะแสดงหลังผู้ขายกดรับออเดอร์ ซึ่งใช้ **1 เครดิต**
- หน้าติดตามพัสดุใช้ได้หลังผู้ขายยืนยันการส่ง และผู้ซื้อรับของ/จ่ายเงินปลายทาง

### ค่าส่ง
- ค่าส่งแยกจากค่าหนังสือ
- ผู้ซื้อและผู้ขายตกลงกันเอง
- ไม่มีระบบพักเงิน (no escrow)

## 5. การชำระเงิน

| รายการ | วิธี |
|---|---|
| ซื้อหนังสือ | เก็บเงินปลายทาง (เงินสด) ทั้งนัดรับและส่งพัสดุ |
| เติมเครดิตผู้ขาย | QR + สลิปของแพลตฟอร์ม (ยังคงไว้) |

## 6. หน้าออเดอร์รายละเอียด

`/orders/[id]` แสดง:
- ไทม์ไลน์สถานะ + ฝ่ายที่ต้องทำต่อ + เวลาที่เหลือ
- หนังสือ + เกรด + ราคา + ค่าส่งแยก
- แชทในออเดอร์ (เปิดหลังผู้ขายรับคำขอ)
- ข้อมูลอีกฝ่ายแบบไม่เปิดเผยตัวตน: ชื่อเล่น/ชื่อร้าน, คะแนน, จำนวนไม่ไปตามนัด (เฉพาะข้อมูลผู้ขาย)
- ปุ่มตามสถานะ: รับ/ปฏิเสธคำขอ, ยืนยันการส่ง, ใส่เลขพัสดุ, รับของ+ถ่ายรูป, ให้คะแนน, แจ้งปัญหา
- ไม่มีปุ่มโทร, `tel:`, เบอร์โทร, LINE ID, เลขบัญชี, QR หรือสลิปในออเดอร์

## 7. ฟีเจอร์ที่ยังเป็น mock / รอ backend

- **แนะนำหนังสือ:** แบนเนอร์ “เรื่องนี้คุณอาจสนใจ” ใช้หนังสือเล่มแรกของหมวดที่เลือกเป็น mockup รอ API แนะนำจาก backend
- **ISBN lookup:** frontend อ่านเลขบาร์โค้ด/รับเลข ISBN แล้วให้กรอกข้อมูลหนังสือเอง ยังไม่มีการดึงชื่อ/ปกอัตโนมัติ
- **การแจ้งเตือน:** ใช้ข้อมูล mock + ออเดอร์ในหน่วยความจำ ยังไม่มี push/LINE API จริง
- **แชท/รีวิว:** ยังไม่บันทึกข้ามเซสชัน
- **KYC / เครดิต:** การอนุมัติสลิปและการยืนยันตัวตนเป็น mock
- **Admin:** `/admin` (Phase 5) ยังไม่ทำตามที่ตกลง
